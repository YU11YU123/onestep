# OneStep 可点击界面原型

这是独立于 `black-white-components` 的 OneStep 应用项目。当前只验证界面和操作顺序，使用演示数据，不连接数据库、Windows 系统能力或真实 DeepSeek API。

截至 2026-08-08，多轮界面与交互反馈已实现。下一项是统一核心动效；当前只有 hover、弹窗和提示条等零散基础过渡，不能视为动效阶段已经完成。

本轮使用的 UI 组件从 `../black-white-components/src/components/ui` 原样取用并放入应用自己的 `src/components/ui`。这是 shadcn/ui 的源码归属方式；组件库本身保持只读。

## 启动

```powershell
npm.cmd install
npm.cmd run dev
```

浏览器打开 Vite 输出的本地地址。浏览器页面处于焦点时，可用 `Ctrl+Alt+Space` 模拟快捷记录。

## 当前原型包含

- 收集箱、今天、未来、以后、已完成、项目；
- 四象限视图；
- 当前象限可再次点击取消；取消后任务变回未分类并退回收集箱；
- 任务详情编辑；详情栏可关闭，点击任务后重新展开；
- 已完成任务可以从“已完成”列表恢复到原列表；恢复后仍停留在“已完成”页面，并提示任务回到了哪里；
- 计划日期、截止时间、提醒时间与重复方式保持独立；截止和提醒使用自定义月历加小时/分钟滚轮，月历默认收起，点击日期行后以覆盖时间区域的近正方形大日期格浮层展开，选中后自动收回且不拉长组件，分钟可选 00–59；重复可选一次性或每天重复；
- 项目使用自定义黑白选单，不调用系统原生蓝色下拉框；
- 计划日期暂时试用单行入口：点击后选择今天、明天、具体日期或以后再做；选择具体日期后自动进入“未来”，等待用户体验后决定保留或回退；
- 左侧加号新增自定义项目；双击项目名称后在原位置全选重命名，按 Enter、点击右侧圆角对勾或点击页面其他位置均会保存，按 Esc 放弃；
- 顶部只保留一个“记下一件事”入口，左侧不重复放“快速记录”；
- 快捷记录输入提示为“你现在在想什么？”，支持图片粘贴预览；弹窗已加宽并提高输入区高度，标题、说明、图标、底栏和提交按钮已经做过字号、间距与垂直对齐调整；
- 右侧任务详情和左下角用户区域已提高字号；
- 左下角头像省略号打开账户菜单，只显示设置、剩余用量和版本；快捷键统一放在设置页；“剩余用量”可进入供应商、请求地址、模型与 API Key 配置原型；详情标题栏不再保留无功能的省略号占位；
- 快捷记录组合键可在设置中的真实输入框内重新录制，Esc 取消；录制前按键框保持空白，保存后浏览器焦点内的快捷记录监听同步更新；AI 接口不在设置列表重复出现，只从账户菜单“剩余用量”进入；
- 主内容标题使用明确的中文无衬线字体并统一三层文字间距；四象限页的标题、任务、动作标签和搜索栏已提高字号；
- 任务卡回形针附件图标紧跟标题并保持垂直对齐；
- AI 入口的图标、中文字体、字重、行距和箭头已重新平衡；“当前第一步”标题与各步骤之间的距离已收紧；
- 右侧详情各主板块统一使用 16px 垂直间距；短任务标题保持单行，长标题按内容增高；
- 安排明天；
- AI 第一步模拟拆解；结果页可输入反馈，操作按钮为“上一步”“重拆”“采用”，采用后可在“当前第一步”卡片撤销并恢复原步骤。

## 当前明确没有

- 没有 SQLite 或其他真实数据库，刷新页面会恢复演示数据；
- 没有真正的 Windows 全局快捷键、托盘和系统通知；
- “每天重复”当前只保存内存选项，不会自动生成下一次任务；
- 没有接入 DeepSeek，也没有真实个人记忆；
- AI 接口配置仅保存在页面内存，不测试连接、不发请求、不持久保存 Key；
- 没有安装包、云同步或手机端。

完整交接状态见 `../PROGRESS.md`，下一步顺序见 `../开发顺序-大白话.md`。

## 当前验证基线

- `npm.cmd run typecheck`
- `npm.cmd run lint`
- `npm.cmd run build`
- 调试浏览器和本地页面就绪后运行 `node scripts/smoke-ui.mjs`：当前覆盖 36 项交互并生成 16 张验收截图。

当前快捷记录创建的演示任务会自动带上第一个演示项目；正式需求要求收集箱项目可为空。这是已记录的原型偏差，不应直接带入本地持久化。
