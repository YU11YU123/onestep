# 决策与待确认项

## 用户已经确认

- Windows 优先，未来考虑手机端。
- 本地数据优先，后期考虑云同步。
- 由 Codex 继续直接实施，不只提供教程。
- 快捷记录支持文字和剪贴板图片。
- 需要收集箱、今天、未来、以后、已完成。
- 需要截止日期、项目，以及紧急不重要、重要不紧急、紧急且重要、不紧急不重要四个象限；不使用高/中/低优先级。
- 使用 DeepSeek API 拆第一步并形成个人做事记忆。
- 第一版连续试用 14 天，并持续优化。

## 已确认的原型交互决定

- 四象限只使用“紧急不重要、重要不紧急、紧急且重要、不紧急不重要”，不显示高/中/低优先级。
- 主界面只保留顶部“记下一件事”，不再重复显示左侧“快速记录”。
- 快捷记录提示为“你现在在想什么？”。
- 已完成任务必须能恢复；恢复后留在“已完成”页面并提示去向，不自动跳转到“今天”；右侧任务详情可以关闭，点击任务时再展开。
- 截止时间和提醒时间采用自定义月历加小时、分钟滚轮，可精确到任意分钟；月历默认收起，点击日期行后以近正方形大日期格浮层覆盖时间区域，不撑高组件，并在选中后自动收回；项目选择采用自定义黑白选单。
- 项目可通过加号新增；双击项目名后原位全选重命名。
- 项目重命名按 Enter、点击右侧确认或点击页面其他位置保存，按 Esc 放弃。
- 项目确认按钮位于整行最右侧，使用与外层一致的 8px 圆角，不使用圆形按钮。
- 再次点击当前已选象限会取消分类，并把任务退回收集箱成为“未分类”；不会留在原列表或自动归入“不紧急不重要”。
- 右侧任务详情、左下角用户区和快捷记录弹窗已经按用户反馈提高可读性并调整对齐。
- AI 建议不合适时可输入反馈并重新拆解；重新生成只更新建议预览，用户确认采用前不修改原任务。
- 任务卡附件图标紧跟标题显示，不单独占据一段视觉间距。
- 右侧详情主板块统一使用同一套垂直间距；任务标题不固定占两行，只有内容较长时才增高。
- AI 结果页使用“上一步”“重拆”“采用”三个短操作；采用后必须在任务中提供可见的“撤销”。
- 左侧独立“设置”入口移入头像省略号账户菜单；剩余用量未接入时显示“尚未接入”，不展示假额度。
- 任务详情标题栏不保留无功能的省略号按钮；计划日期、截止时间、提醒时间和重复方式分开显示。
- 重复方式首版提供“一次性”和“每天重复”。
- “剩余用量”卡片是 AI 接口配置的唯一入口；设置列表不重复展示“AI 接口与用量”。配置页包含供应商、请求地址、模型名称和 API Key。当前只做内存态 UX，不伪装为已接通。
- 快捷记录组合键使用设置中的真实可聚焦输入框录制；尚未输入时输入框保持空白，录制成功后浏览器原型监听立即更新。
- 账户菜单不重复展示“快捷记录”行；快捷键查看和修改只保留在设置页。

## 为了先推进而暂定的决定

这些不是用户已确认事实，猜错会改变体验，但不阻碍搭框架：

| 问题 | 暂定值 | 猜错的代价 |
|---|---|---|
| 产品名 | 第一步 OneStep | 只影响文案和包名，后续可改 |
| 默认快捷键 | `Ctrl+Alt+Space`，可配置 | 可能与现有软件冲突 |
| 快捷保存 | `Enter` 保存，`Shift+Enter` 换行 | 可能不符合输入习惯 |
| 主窗口关闭 | 缩到托盘，以保证提醒 | 用户可能以为已经完全退出 |
| 明日计划提醒 | 每天 18:00，可关闭 | 可能不符合下班时间 |
| 明日任务建议上限 | 7 条，只提示不强制 | 可能过多或过少 |
| 单任务提醒 | 首版 1 个提醒时间 | 无法覆盖多阶段催办 |
| AI 默认上下文 | 当前任务；相关记忆需主动允许 | 记忆感较弱，但隐私更稳妥 |
| AI 默认模型 | 接入时核验 DeepSeek 官方当前可用模型，通过设置控制 | 供应商模型变化会失效 |
| 核心动效节奏 | 初始 120–220ms，并支持系统“减少动态效果” | 过慢会拖沓，过强会分散注意力；需体验后再固定 |
| 软删除保留期 | 30 天 | 占用更多本地空间 |
| 第 3 步数据载体 | 进入阶段前决定浏览器持久化适配器，或提前最小 Tauri/SQLite 承载层 | 选错会增加一次迁移，或提前引入桌面构建环境 |

## 实施到对应阶段前必须确认

1. 用户是否已有 DeepSeek API Key，以及可接受的单月 API 费用上限。
2. 工作任务是否包含公司机密；哪些内容绝对不能发送给外部 AI。
3. 通知希望只响一次，还是截止前需要默认的提前提醒。
4. 图片是否只需要截图，还是还需要 PDF、Word 等文件附件。
5. 是否允许软件开机自启；公司电脑是否限制安装、托盘程序或系统通知。
6. 每天重复任务完成后，是生成一个新的下一次任务，还是复用同一任务并重置完成状态；该决定会影响历史记录和数据库结构，必须在本地数据阶段建表前确认。
7. 第 3 步使用哪种本地数据载体；当前纯浏览器应用不能直接使用普通桌面 SQLite，若提前引入 Tauri/Rust 必须先确认安装与架构影响。
