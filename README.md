# 第一步 OneStep（暂名）

一个面向个人使用的 Windows ADHD 友好效率软件：先无打扰地接住事情，再在合适的时间提醒，并把模糊任务变成可以马上执行的第一步。

## 当前状态

- 2026-08-08：需求基线、可点击原型和截至目前的多轮界面与交互反馈已经实现；任务详情已拆分计划日期、截止时间、提醒时间和重复方式，AI 拆解已具备反馈重拆、采用和撤销的演示闭环。
- 当前处于[大白话开发顺序](开发顺序-大白话.md)的第 2 步：下一项是统一弹窗、详情、任务状态、选择层和 AI 状态切换的核心动效；用户体验并确认框架后再进入本地数据库。
- 原型位于 `onestep-app/`，仍使用演示数据；刷新会恢复初始内容，不代表任务已经持久保存。
- 左下角账户菜单只保留“设置、剩余用量、版本”信息层级；快捷键统一放在设置页，剩余用量明确显示“尚未接入”，不伪造真实额度。
- “剩余用量”可进入 AI 接口配置原型，填写供应商、请求地址、模型和 API Key；快捷记录组合键也可在设置中重新录制。两者当前都只在页面内存中演示。
- 当前自动化基线为类型检查、代码检查、生产构建和 36 项浏览器回归；完整结果与新会话接手位置见 `PROGRESS.md`。
- `black-white-components/` 只是用户独立维护的开发素材库，不属于 OneStep 产品模块；OneStep 已将需要的组件源码放进自己的目录，素材库保持只读。
- 第一轮发布目标是本地单机版，完成后由用户连续试用 14 天。

## 第一版必须解决

1. 领导布置任务后，可以用全局快捷键立刻记进收集箱。
2. 截止时间到达时能够提醒，且逾期事项不会静默消失。
3. 每天能看见今天要做什么，并提前安排明天。
4. 遇到模糊任务时，可调用 DeepSeek，把它拆成一个可以立刻开始的第一步。

## 产品原则

`先接住 > 再整理 > 再提醒 > 最后才智能化`。

快捷记录不能因为项目、四象限或 AI 还没有填写而失败。AI 不在线时，记录、查看、编辑和提醒仍必须可用。四象限就是“紧急不重要、重要不紧急、紧急且重要、不紧急不重要”，不另设高/中/低优先级。
